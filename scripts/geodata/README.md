# scripts/geodata

Qui vanno gli script (Node, `.mjs`) che scaricano **una volta sola** i dati geografici per le tappe di M2 (Rifredi, Firenze, valle dell'Arno, Italia) e li salvano, semplificati e compatti, in `public/data/`.

Fonti, licenze, bounding box e query di partenza: vedi `docs/ASSETS.md`.

Regole: nessun dato scaricato a runtime; nessun luogo privato; credito «© OpenStreetMap contributors» in `CREDITS.md`.
